# NettoDeals.ch 🇨🇭

Ein minimalistisches, autonomes und self-hosted Elektronik-Deal-Portal für den Schweizer Markt, das den echten "Effektivpreis" (nach Abzug von Gutscheinen und Zahlungs-Boni) berechnet.

## Tech Stack
- **Backend:** Python / FastAPI
- **Database:** SQLite (lokal mit persistentem Volume)
- **Frontend:** Tailwind CSS (via CDN) & Jinja2 Templates
- **Hosting:** Dezentrales Flux-Netzwerk (DePIN) via Docker
